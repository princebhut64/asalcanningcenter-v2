# Asal Canning Center - Responsive Static Website

## Project structure

- `index.html` — Home
- `about.html` — About Us
- `products.html` — Products
- `news.html` — News & Media
- `gallery.html` — Gallery
- `contact.html` — Contact Us
- `css/shared.css` — Shared responsive/mobile styles
- `css/home.css` — Home page styles
- `css/about.css` — About page styles
- `css/products.css` — Products page styles
- `css/news.css` — News & Media page styles
- `css/gallery.css` — Gallery page styles
- `css/contact.css` — Contact page styles
- `js/main.js` — Shared navigation and responsive behavior
- `js/*.js` — Page-specific JavaScript

## Notes

The six supplied HTML pages were combined into one linked static project. Navigation paths were normalized to the new filenames and the Products page was given the same responsive mobile navigation behavior as the other pages.

The project keeps the original external assets (Google Fonts, Font Awesome, AOS, Unsplash/API image URLs) so an internet connection is needed for those remote assets.

Open `index.html` to start the site.
